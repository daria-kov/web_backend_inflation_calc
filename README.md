### Домены и методы

#### Домен «Услуги»

Домен отвечает за работу с услугами:

* `GET /api/consumer_categories` — получение списка опубликованных услуг с фильтрацией по дате.
* `POST /api/consumer_categories` — создание черновика услуги с загрузкой изображения и видео.
* `GET /api/consumer_categories/draft` — получение черновика текущего пользователя.
* `PUT /api/consumer_categories/:id/publish` — публикация услуги и заполнение её основных данных.
* `GET /api/consumer_categories/feed` — получение ленты опубликованных услуг.
* `GET /api/consumer_categories/feed/:id?next=true` — получение следующей услуги в ленте.
* `POST /api/consumer_categories/:id/like` — установка или снятие лайка.
* `DELETE /api/consumer_categories/:id` — мягкое удаление услуги с изменением её статуса на `deleted`.

#### Домен «Пользователи»

Домен отвечает за работу с пользователями:

* `POST /api/users/register` — регистрация нового пользователя.
* `POST /api/users/auth` — заглушка для авторизации, реализация предусмотрена в следующей лабораторной работе.
* `POST /api/users/deauth` — заглушка для выхода пользователя, реализация предусмотрена в следующей лабораторной работе.

### Основные таблицы базы данных

* `consumer_categories` — услуги, их статусы, данные о создателе, даты и имена файлов.
* `likes` — лайки пользователей услугам.
* `users` — зарегистрированные пользователи.
